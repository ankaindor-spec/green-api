# Чат Telegram через GREEN-API

Личный чат в браузере для одного экземпляра GREEN-API тарифа «Разработчик» (Telegram). Исходящие сообщения уходят методом `SendMessage`, входящие забираются методом `ReceiveNotification`.

## Требования

Node.js 22 или новее.

Нужен один экземпляр Telegram в [кабинете GREEN-API](https://console.green-api.com/).

## Локальный запуск

```bash
npm install
npm run dev
```

`npm run dev` запускает Vite. Откройте адрес из вывода команды, обычно `http://localhost:5173`.

## Учётные данные

На экране входа введите значения из кабинета GREEN-API (карточка экземпляра):

- `idInstance` — идентификатор экземпляра, только цифры;
- `apiTokenInstance` — токен экземпляра;
- `apiUrl` — адрес API. Поле можно оставить пустым.

Пустой `apiUrl` приложение заменяет на `https://` + первые четыре цифры `idInstance` + `.api.green-api.com`. Для `idInstance` `4100123456` получится `https://4100.api.green-api.com`. Свой адрес указывайте полным URL с протоколом `https`.

Значения вводятся в браузере и записываются в `localStorage`. В репозитории и в сборке их нет.

## Авторизация экземпляра

Чат открывается только при состоянии экземпляра `authorized` (`getStateInstance`). QR на сайте нет. Привяжите устройство в кабинете: в Telegram откройте «Настройки → Устройства → Привязать устройство» и отсканируйте QR кабинета.

Пока экземпляр не авторизован, заблокирован, ограничен, запускается или ждёт пароль двухфакторной защиты, чат закрыт. Запуск может занять до 5 минут. После смены состояния нажмите «Проверить снова».

## Приём уведомлений

`webhookUrl` должен быть пустым, входящие уведомления включены (`incomingWebhook` равен `yes`).

Если в кабинете задан вебхук или входящие выключены, нажмите «Включить приём». Приложение вызовет `setSettings` с телом:

```json
{ "webhookUrl": "", "incomingWebhook": "yes" }
```

Экземпляр после сохранения настроек перезапускается. Применение занимает до 5 минут. Пока `webhookUrl` не пустой, `ReceiveNotification` отвечает `400`. После очистки подождите около минуты и нажмите «Проверить снова». Те же два поля можно выставить вручную в кабинете.

## Переписка

Для демонстрации нужен второй аккаунт Telegram на другом номере телефона. Диалог с тем же номером, которым авторизован экземпляр, показать нельзя.

Новый чат создаётся по номеру: международный формат, от 8 до 15 цифр, без плюса. Пробелы, скобки и дефисы можно. Приложение вызывает `CheckAccount`. Если номер в Telegram не находится, ответ содержит `exist: false`, чат не создаётся.

В `SendMessage` всегда уходит `chatId` из ответа `CheckAccount`. Сохранённый `chatId` повторно не проверяется, параметр `force` не передаётся.

На экране видны текстовые сообщения уже открытых чатов. Исходящий текст — до 4096 символов. История чатов остаётся в `localStorage` этого браузера и привязана к `idInstance`. Кнопка «Выйти» стирает только введённые учётные данные.

Держите одну вкладку. У экземпляра одна очередь `ReceiveNotification`: вторая вкладка её не читает и сообщает, что приём идёт в другой вкладке.

Уведомления ждут в очереди 24 часа. Ответ, пришедший при закрытой вкладке, появится после следующего открытия, если уведомление ещё не удалено. Прочитанное уведомление приложение снимает методом `deleteNotification`.

## Лимиты тарифа «Разработчик»

- 3 чата в месяц. Четвёртый чат возвращает `466` и список уже использованных `chatId`.
- Один и тот же человек, которому один раз написали как `номер@c.us`, а другой раз как `chatId`, считается двумя чатами.
- `CheckAccount` — 100 вызовов в месяц. Частые проверки номера, которого нет в Telegram, могут вернуть `469`.

## Проверка и сборка

```bash
npm test
npm run build
```

`npm test` запускает Vitest (`vitest run`). `npm run build` проверяет TypeScript и собирает приложение (`tsc --noEmit && vite build`). Собранные файлы можно открыть командой `npm run preview`.
